# 07 · 提示词库（可直接复制）

> 本文件收集本体系各环节可直接复用的提示词。把 `{{ }}` 占位符替换成你的实际内容。

## 1. 竞品拆解（挖信息盲区 · 四步法第一步）

```
请分析这 5 篇竞品内容，输出：
1. 它们共同覆盖的共识信息；
2. 每篇独有的差异化卖点；
3. 所有文章都没提到、但用户可能关心的信息盲区；
4. 读者高频抱怨的未满足需求。

竞品内容如下：
{{粘贴 Top5 竞品正文}}
```

**进阶版（带内容覆盖矩阵）**：

```
请对比分析以下竞品页面，输出 Markdown 表格「内容覆盖度对比矩阵」：
- 行 = 所有竞品覆盖的子话题/实体/问题
- 列 = 各竞品（+ 标注"是否覆盖"）
再单独列出：目标读者最可能追问、但当前 Top10 全部缺失的 10 个信息盲区，
并按搜索意图价值从高到低排序。
```

## 2. AI 可读性重构（四步法第二步）

```
请将以下内容重构为 AI 爬虫最爱解析的结构：
1. 用清晰的问题式 H2/H3 标题层级；
2. 每个段落控制在 2–3 句话，避免长文本块；
3. 关键数据和结论用列表/表格呈现；
4. 全文自然嵌入同义词变体（LSI 关键词），密度控制在 2–3%；
5. 在文章前部设置"快速导航区"，直接回答用户最可能的 5 个追问。

内容如下：
{{粘贴原文}}
```

## 3. 内容 GEO 优化（通用）

```
你是 GEO（生成式引擎优化）专家。请优化以下内容，让 ChatGPT/Perplexity/Gemini/Claude
更容易引用它：
1. 开头 40 字内给出可直接引用的核心结论（一句话）；
2. 为每个关键数据点补充来源与日期；
3. 把任何超过 3 句的段落拆开；
4. 添加一个 FAQ 区块（5 个问题，直接回答）；
5. 生成含日期与作者的 Article Schema（JSON-LD）。
6. 标注作者资质（如果原文没有，请提示我补充）。
```

## 4. GEO 审计（诊断"为什么 AI 不引用"）

```
请按 FAST 框架审计以下页面/站点，输出问题清单 + 修复优先级（高/中/低）：
- F Fetchable：AI 能否不执行 JS 就读取核心信息？
- A Accessible：语义化 HTML、H1-H6 层级、alt 文本是否到位？
- S Structured：是否缺少 Article/FAQPage/Person/Organization Schema？
- T Trim：是否存在冗余脚本、资源未压缩、JS 依赖过多？

再检查：robots.txt 是否拦截了 GPTBot/ClaudeBot/PerplexityBot/Google-Extended？
是否配置了 llms.txt？内容是否有明确日期、作者、来源？

页面/站点：
{{URL 或粘贴 HTML}}
```
