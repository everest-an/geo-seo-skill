## 1. 研究论文（GEO 学术基石）

| 论文 | 要点 |
|------|------|
| [GEO: Generative Engine Optimization](https://arxiv.org/abs/2311.09735)（Princeton，KDD 2024） | 开山之作，系统引入 GEO 概念，证实最高 **40%** 可见性提升；引用/统计内容 +30–40% |
| [Generative Engine Optimization: How to Dominate AI Search](https://arxiv.org/abs/2509.08919)（2025） | 揭示 AI 引擎对 **earned media** 的系统性偏好（高于品牌自有内容） |
| [AutoGEO](https://openreview.net/forum?id=K8EinVWtUB)（ICLR 2026） | 自动学习生成式引擎偏好、提取优化规则 |
| [E-GEO](https://arxiv.org/abs/2511.20867) | 电商 GEO 测试集（7000+ 商品查询、15 种改写启发式） |
| [BRIGHT](https://arxiv.org/abs/2407.12883) | 推理密集检索基准 |
| [Search-o1](https://arxiv.org/abs/2501.05366) | Agentic RAG 搜索推理 |
