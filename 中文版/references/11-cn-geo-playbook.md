# 11 · 国内 GEO 实战手册：打赢中国 AI 搜索市场

> 面向百度 AI / 文心 / 豆包 / 千问 / 元宝 / Kimi / DeepSeek 的数据驱动打法。
> 本文件所有数字来自公开 **CN-GEO 引用数据集**实算（187,818 条去重引用、19,190 条域名×平台记录、
> 12 个平台终端；数据版本 2.0.1，2026-07-14 发布）。
> 上游数据：github.com/yaojingang/geo-citation-lab · 手册提炼自 MIT 许可的 GeoLook skill（github.com/aigclink/geolook）。

## 1. 会改变资源分配的那个数字：官网只占 1.37%

| 信源类别 | 占全库引用 | 域名数 |
|---|---:|---:|
| 内容平台（qq / toutiao / baidu / iesdouyin） | **16.4%** | 4 |
| 综合新闻媒体 | **13.6%** | 68 |
| **商业推荐与榜单站** | **9.1%** | **28** |
| **品牌官网 / 企业站** | **1.37%** | 52 |

**读法**：在国内 AI 引用生态里，官网是**事实源，不是引用源**。
"把官网做好就会被 AI 引用"是战略性误判。28 个榜单站域名就吃掉 9.1% 的引用，
还占据答案最靠前的位置（见第 4 节）。

- 官网的真实职能：让 AI 描述你时口径正确（行业对、事实对、措辞对），并给外部站一个可信落点。
- 资源分配：官网做到"可抓取 + 有定义 + 有结构化数据 + 口径统一"就够了，
  **剩下的力气花在外部信源上**。

## 2. 平台生态割据（CN-GEO 实算，不是印象）

| 平台 | Top8 集中度 | 自家生态头部信源 | 你要准备的东西 |
|---|---:|---|---|
| **百度 AI** | **66.2%** | baidu.com **37.7%** | 百度百科 / 百家号 / 百度知道——不做基本进不去 |
| **文心** | **66.8%** | baidu.com **29.0%** | 同上 |
| **千问** | 61.0% | **sm.cn（夸克/神马）19.2%** | **优化夸克搜索收录 ≈ 优化千问**——很多人没意识到 |
| **豆包 App** | 54.3% | iesdouyin.com **28.1%** | **抖音图文与视频是主入口** |
| **Kimi** | 47.9% | 无自家生态（sohu 15.8%、cnblogs 9.1%） | 长报告、白皮书、结构化长文；技术社区内容 |
| **豆包 web** | 46.0% | iesdouyin.com 12.0% | 同豆包 App，但外部内容机会更大 |
| **腾讯元宝** | 43.8% | qq.com **20.5%** | **公众号、腾讯新闻**——元宝的护城河 |
| **DeepSeek** | **21.8%** | **无自家生态，最分散最中立** | 完整论证、可追溯数字、明确边界；**内容质量回报最高** |
| **抖音 AI** | 100% | 只引 iesdouyin.com 一个域名 | 外部内容进不去——**不值得单独投入** |

读法：集中度越高越封闭，越要走它的生态；集中度低的（DeepSeek）靠通用内容质量竞争。

**实操含义**：一份内容至少出三个版本——官网权威页（长、全、带 schema）、
公众号版（面向元宝/微信搜索）、垂类社区版（面向豆包/千问）。

## 3. Web ≠ App：实测，不是洁癖

同一产品不同终端的信源集合：

| 产品 | web 域名数 | App 域名数 | **Jaccard 相似度** |
|---|---:|---:|---:|
| 千问 | 1,036 | 677 | **24.5%** |
| 元宝 | 2,989 | 3,206 | **31.4%** |
| 豆包 | 2,701 | 2,283 | 47.3% |
| DeepSeek | 2,666 | 2,337 | 51.6% |

千问 web 和 App 信源只有 **24.5%** 重合——拿 web 端结论推 App 端表现，四分之三是错的。
**每个平台+终端必须分开采样、分开算指标**，绝不合并成一条"提及率"。

## 4. 引用位置：谁被放在答案最前面

`average_quote_position` 越小 = 越靠前 = 权重越高。样本 ≥300 的头部：

| 域名 | 平均位置 | 引用量 | 类型 |
|---|---:|---:|---|
| sm.cn | 5.31 | 6,501 | 搜索代理（阿里） |
| **cnpp.cn** | 6.10 | 3,429 | **榜单站** |
| **maigoo.com（买购网）** | 6.36 | 6,741 | **榜单站** |
| **phb123.com（排行榜123）** | 7.12 | 437 | **榜单站** |
| iimedia.cn（艾媒） | 7.27 | 379 | 行业研究 |
| **cnpp100.com** | 7.35 | 783 | **榜单站** |

**榜单站霸榜。** AI 回答"哪个好/怎么选"时，最省事的做法就是抄一份现成榜单。

## 5. 外部信源优先级（替换一切主观排序）

1. **跨平台通吃层**（覆盖全部 11 个平台端，一次投入全平台受益）
   - 榜单/品牌库站：`maigoo.com`、`chinapp.com`、`cnpp.cn`、`phb123.com`、`cnpp100.com`
     —— **性价比最高，大多数团队漏掉了**
   - 内容平台：`qq.com`（公众号/腾讯新闻）、`toutiao.com`（头条号）
   - 新闻媒体：`sohu.com`、`163.com`、`sina.cn`；消费决策：`smzdm.com`
2. **平台生态层**（按你最在意的平台选）
   - 百度 AI / 文心 → 百度百科、百家号、百度知道
   - 豆包 → 抖音图文与视频、头条号
   - 元宝 → 微信公众号、腾讯新闻
   - 千问 → **夸克/神马搜索收录**、阿里系内容
3. **专业内容层**（技术/B2B 适用）：`cnblogs.com`、`csdn.net`、`zhihu.com`、`zol.com.cn`、`36kr.com`；
   行业研究 `askci.com`、`iimedia.cn`（引用位置很靠前）
4. **官网**——必做，但别指望它带引用（1.37%）

**纪律**：上表是行业大盘，你的行业未必一样。采样后一定要看报告里的
「AI 实际引用的信源域名 Top」——**那才是你行业当下真实的分发地图，以它为准**。

## 6. 国内内容工程（CN-GEO 方法层）

**把内容写成「证据页」，不是「观点页」。** 每个要打的问题，页面至少具备：

1. 一句可直接摘走的定义
2. 2–5 个带单位、带出处的数字
3. 一个对比块（表格最佳）
4. 一个步骤块
5. 适用与不适用场景（写清楚"不适合谁"反而提高可信度）

骨架示例：

```
标题：<目标问题的原话>
1. 什么是 X（一句定义 + 一段展开）
2. 关键数字（3–5 条，每条带来源和日期）
3. X vs Y（表格，同口径维度）
4. 怎么做（5 步）
5. 适用与不适用场景
6. 常见问题（3–5 条）
7. 参考来源（真实可点开）
```

**纯 Q&A 格式没有增益（实测 −5.7%）**——格式不是重点，定义/数字/结构/对题性才是。
FAQ 的唯一价值是问法召回：用真实用户问法，答案第一句给结论。

## 7. 采样纪律（证据等级）

**没有原始答案/截图/采样环境记录的，不许标成"真实采样"。**

| 等级 | 含义 |
|---|---|
| A | 人工/浏览器真实样本，有答案原文与来源链接 |
| B | API 可复现样本（注明是否联网） |
| C | 合成演示 / 推断 |
| D | 待复核 |

规则：
- **API ≠ 网页端**。DeepSeek 官方 API 不联网，测的是参数化知识，不是检索。分开记，绝不合并。
- **Web ≠ App**。每个平台+终端单独一行。
- 指标至少四层：提及率、首位率/Top3、描述准确率、引用质量（召回 + 准确）。只看提及率会严重高估效果。
- 归因默认写"**观察相关**"。提高置信度必须有基线窗口 + 观察窗口 + 对照 Prompt + 竞品对照 + 外部事件记录。
- 手动采样：每题新开对话；记录环境（sandbox/无痕/专用 Profile = A 级，个人日常账号自动降级 D 级）；
  "没提到品牌"也要记录——那是最重要的数据。

## 8. 语言与地域

- 国内市场：中文简体，用用户真实说法（"XX 好用吗" "XX 和 YY 哪个好" "XX 多少钱"），不要翻译腔。
- **中文 Prompt 触发的检索强度低于英文**（跨平台实验：英文平均引用 11.68 vs 中文 10.41；
  Google 差距最大 11.57 vs 7.53）。做海外就老老实实写英文原生内容，别指望中文页被翻译引用。
- 美国域名 + 英文仍是海外绝对主战场（可识别国家里 US 占 82.70–86.76%，英文占 82.90–95.07%）。
